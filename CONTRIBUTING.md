# Contributing

External contributions are not accepted during the private platform-foundation phase.

Before external contributions open, the repository will use Developer Certificate of Origin 1.1 sign-off. Every accepted commit will require a `Signed-off-by` trailer created with `git commit -s`. The public contribution gate also requires a code of conduct, private security-reporting channel, review policy, test instructions, and license checks.

Developer Certificate of Origin 1.1: https://developercertificate.org/
